# MTBLS289

The example images in this folder are from the MTBLS289 dataset, which is a public dataset of WSI/MSI images from a
study, published in the following paper:

> Gerbig, S., Golf, O., Balog, J. et al. Analysis of colorectal adenocarcinoma tissue by desorption electrospray 
> ionization mass spectrometric imaging. Anal Bioanal Chem 403, 2315–2325 (2012).

The dataset is under the [EMBL-EBI](https://www.ebi.ac.uk/about/terms-of-use/) license. A copy of the full dataset can
be found [here](https://huggingface.co/datasets/aryan-f/MTBLS289).
