# imzDesk

imzDesk is an open-source workbench and Python library for whole-slide imaging
(WSI) and mass spectrometry imaging (MSI). Use it to inspect images, compare
pixel spectra, register WSI and MSI data, annotate tissue, and prepare datasets
for analysis or model training.

![The imzDesk workbench displaying registered WSI and MSI data](https://raw.githubusercontent.com/aryan-f/imzDesk/master/assets/imzdesk-demo.webp)
